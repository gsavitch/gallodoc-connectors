# GalloDoc Core v3.0.0 Release Notes

Welcome to the v3.0.0 "Master Release" of GalloDoc Core.

## Stability Status
This release moves GalloDoc Core into **Beta** status ("Development Status :: 4 - Beta").  
While we have achieved feature-completeness for the v3 vision, we will use the coming months to harden the implementation across industrial connectors.

## Key Changes
- **Operational Intelligence**: Full support for `connector_lineage` and `gallounits`.
- **AI/BI Planner**: Integrated planner receipts for deterministic relationship queries.
- **Linker Upgrade**: New candidate-to-confirmed workflow with embedding support.
- **V1 Deprecation**: 6-month parallel support window for v1 clients.

## Migration
Please see the [Migration Guide](docs/migration/v1-to-v3.md) for details on upgrading from v1.
